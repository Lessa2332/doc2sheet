# Doc2Sheet Private — One HTML

Особистий mobile-first інструмент:

**фото документа → друкований/рукописний український текст → таблиця → перевірка → Excel**

## Архітектура

Це навмисно мінімальний варіант:

- `index.html` — весь UI, CSS та JavaScript;
- Gemini API викликається безпосередньо з браузера;
- користувач вставляє власний Gemini API key у поле;
- ключ не записується у localStorage/cookie/IndexedDB;
- фото не завантажується у власне файлове сховище;
- результат редагується у браузері;
- Excel-compatible `.xls` і CSV створюються локально.

## Важливо про API key

Google рекомендує не відкривати API keys у client-side production applications. Цей режим свідомо є **personal-use / BYOK (bring your own key)**: ключ вводить власник і використовує лише для власної сесії. Не використовуйте цей варіант як публічний сервіс для інших людей.

Якщо Google AI Studio видає новий `AQ.*` authorization token, він не є взаємозамінним зі стандартним API key для цього простого `x-goog-api-key` REST-виклику. Для цього HTML потрібен Gemini API key, сумісний з API-key authentication.

## Запуск

Можна відкрити `index.html` через HTTPS-hosting (наприклад GitHub Pages) або локальний статичний сервер.

Для камери на телефоні HTTPS потрібен практично завжди.

## Приватність

Застосунок не має власної БД і не має серверної історії. Фото, base64 та результат живуть у пам'яті сторінки під час сесії. Кнопка «Очистити» видаляє їхні JS-посилання. Браузер сам визначає момент фактичного звільнення пам'яті.

## Відоме обмеження

Експорт `Excel` у цій мінімальній версії — Excel-compatible `.xls` (HTML table), а не сучасний OOXML `.xlsx`. Це зроблено навмисно, щоб зберегти справжню незалежність від npm/CDN. За потреби наступним кроком можна вбудувати локальний XLSX writer.
